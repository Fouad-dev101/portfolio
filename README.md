# FodX portfolio

A static, responsive portfolio for Fouad Sabbani. The page uses plain HTML, CSS, and JavaScript so it can be hosted directly on Netlify, Vercel, GitHub Pages, or any static host.

## Run locally

From this folder, start a static server:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

- Check that every supplied project URL and contact detail is still current.
- Replace the GitHub profile links on projects with repository links where available.
- The featured projects use Fouad's supplied screenshots. RestoReserve still has an illustrative preview until a real screenshot is available.
- Confirm the final canonical domain and social sharing metadata.
- The concept builds for local businesses are practice/pitch work, not client work.

## Hosting

Upload the folder as a static site. No build step, package installation, or environment variables are required. The fonts load from Google Fonts; system sans-serif fallbacks are included.
